多主体归集

支持最多 5 个公司主体，统一归档合同、资质、票据等资料。

扫描件 OCR

图片 / 扫描 PDF 自动识别文字（中文 + 英文），转成可检索文本。

融合检索

FTS5 全文 + 向量语义双路召回，RRF 融合排序并高亮命中。

RAG 问答

基于本地资料的问答，带提示注入隔离，答案可溯源。

密钥走钥匙串

云端 API Key 仅存系统钥匙串（keyring），绝不落库明文。

离线可用

核心检索与资料管理完全本地，无网络也能工作。

为什么是本地优先

企业资料往往含敏感信息。AIDMS 把索引、向量与原文都留在你的机器上，仅在你主动配置 LLM 时才与外部模型通信，且所有出网请求经过 SSRF 防护。你拥有数据的完全控制权。
